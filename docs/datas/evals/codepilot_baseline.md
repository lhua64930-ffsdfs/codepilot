# CodePilot 工程基线（2026-10-31）

这是用于固定回归评测的版本化参考资料，不代表线上服务承诺。

## 证据边界

当前源码以工作区 checkout 为准，通过 workspace.search_code 和 workspace.read_file 检索。
Issue 描述、PR 说明、Review 评论、CI 失败日志、项目文档、上传知识和批准的长期记忆可以进入 RAG。
PR 是否已合并等实时状态必须查询当前 GitHub 或同步的结构化状态；旧文档只提供候选证据。

## 写操作与同步

Agent 的 GitHub 写操作先生成待确认草稿，经有权限的用户人工确认后执行。
GitHub 写入超时可能发生在远端已成功之后。unknown 草稿需要先到 GitHub 核对，不能自动重试。
PR 文件或评论同步网络失败时，保留已有数据并返回部分同步失败；远端成功返回空列表才表示应清空旧记录。

## 部署

生产模式必须关闭 DEMO_MODE，使用个人访问令牌识别用户并按仓库成员关系隔离数据。
升级前先备份数据库，在 backend 执行 python -m alembic upgrade head，再启动应用。
后台重建和只读分析任务通过数据库队列、租约与有限重试恢复。GitHub 写操作不进入自动重试队列。

本资料未提供生产 SLA 百分比，也不包含其他仓库的密钥或私有业务数据。缺少资料时应明确说明无法确定。
