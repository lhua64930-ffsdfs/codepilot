# 5 分钟项目演示

[返回 README](../README.md) · [项目介绍](project_overview.md) · [启动指南](getting_started.md)

## 演示准备

安装依赖后，在 Windows 项目根目录执行：

```powershell
.\scripts\start_docs_preview.ps1
```

打开 `http://127.0.0.1:3019`。脚本使用 `.data/docs-preview/showcase.db`，创建合成仓库、Issue、PR、CI、审批草稿及配套知识文档；关闭 LLM、Milvus、自动 GitHub 同步和反馈通知。它不读取你的实际 GitHub 令牌或私人仓库数据作为展示内容。

日志和进程信息保存在 `.data/docs-preview`。如果前后端端口被占用，可使用 `-BackendPort`、`-FrontendPort` 参数指定其他端口。结束演示后按脚本输出的 PID 停止对应进程。

## 建议演示顺序

| 时间 | 操作 | 说明重点 |
| --- | --- | --- |
| 0:00–0:40 | 打开工作台，选择 `codepilot-demo` | 项目、对话、Issue、PR 和 CI 共享仓库上下文 |
| 0:40–1:30 | 打开 Issue #12，点击“分析当前 Issue” | 从问题描述得到分类、优先级和处理建议 |
| 1:30–2:20 | 切换 CI，选择 `Backend · pytest`，点击“分析当前 CI” | 查看失败 job、错误日志、排查计划和合并阻塞判断 |
| 2:20–3:20 | 打开 RAG 工作室，提问“根据 codepilot_baseline.md，PR 文件或评论同步网络失败时应保留还是清空旧记录？” | 展示检索证据、来源引用和明确的降级状态 |
| 3:20–4:10 | 打开 Drafts，查看待确认的 PR #24 草稿 | 解释人工确认、权限和执行防重；演示时不点击外部执行 |
| 4:10–5:00 | 打开 Evals 并展示架构图 | 解释固定基线、执行状态与回答质量如何区分 |

截图环境没有真实仓库 checkout，源码关联或 PR 快照步骤可能提示不可用。展示真实代码分析时，应另行连接本人授权的仓库。

## 完整模型演示需要什么

- 已授权且完成同步的 GitHub 仓库；代码分析还需要可用的本地 checkout。
- 可访问的 LLM，以及配置匹配的 Embedding 和 Rerank。
- Milvus 可用，知识文档索引完成，检索界面不再处于向量降级状态。
- 运行固定评测集并保留实际报告，而不是预填分数。
